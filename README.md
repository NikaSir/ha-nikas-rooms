# NikaS Rooms for Home Assistant

Автономная панель **«Помещения»** для Home Assistant NikaS.

Новая панель устанавливается параллельно рабочей YAML-версии:

| Панель | Маршрут | Состояние |
| --- | --- | --- |
| Существующая YAML «Помещения» | `/dashboard-rooms/rooms` | сохраняется без изменений |
| Новая Rooms v11 | `/dashboard-rooms-v11/rooms` | владелец — эта интеграция |

Репозиторий основной панели **«Дом»** не является зависимостью и не изменяется. Ссылка из «Дома» остаётся на старой YAML-панели до отдельного решения после проверки v11 на телефоне.

## Основа

Функциональная основа — `Home_Assistant_Rooms_v10_8_18_PRIMARY_CLIMATE_LABEL.yaml` (SHA-256 `a9bceb0a48edd0932e6099149d55e5bde5bc9f6b427b906a4648c493229149a0`). Неизменная копия хранится в `references/`.

Rooms v11 сохраняет 18 помещений и переносит модель на живые реестры Home Assistant:

```text
Area → Device → Entity → Labels → hass.states
```

- помещения сопоставляются и с обычными, и с нумерованными названиями Area;
- основной датчик температуры/влажности определяется ярлыком `Датчик климата помещения`;
- видимы устройства с ярлыками `В эксплуатации`, `На обслуживании` и `Требует замены`;
- `Резерв` и `Выведено из эксплуатации` исключены из рабочих карточек, но остаются доступны в диагностике;
- приоритет сводки: тревога → недоступность → открытие → активность → спокойно;
- прямых команд из панели нет: карточка открывает штатное окно `more-info` Home Assistant.

## Интерфейс

- автономный bundle без runtime-импортов из других репозиториев;
- фиксированные Header и нижнее меню;
- прокрутка только рабочей области;
- pinch-to-zoom 75–200%;
- двойной тап двумя пальцами сбрасывает масштаб к 100%;
- обновления `hass.states` меняют только существующие значения и статусы;
- маршруты комнат: `/dashboard-rooms-v11/room-<slug>`;
- диагностика: `/dashboard-rooms-v11/room-<slug>/diagnostics`.

## Установка для проверки

1. Добавить `NikaSir/ha-nikas-rooms` в HACS как пользовательский репозиторий категории **Integration**.
2. Установить **NikaS Rooms**.
3. Перезапустить Home Assistant.
4. Добавить интеграцию **NikaS Rooms** в `Настройки → Устройства и службы`.
5. Открыть **Помещения · новая** в боковом меню.
6. Проверить адрес `/dashboard-rooms-v11/rooms` на телефоне.

Обновления публикуются через ветку `main`; GitHub Releases не требуются.

## Защита маршрутов

Интеграция никогда не регистрирует и не удаляет `/dashboard-rooms`. Если `/dashboard-rooms-v11` уже занят, она оставляет существующего владельца без изменений и пишет предупреждение в журнал Home Assistant. При выгрузке удаляется только маршрут, который зарегистрировала сама интеграция.
