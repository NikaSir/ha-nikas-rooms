# Rooms v11 — соответствие NikaS UI Standard v1.9

| Требование | Реализация |
| --- | --- |
| Уникальный владелец маршрута | `nikas_rooms` регистрирует только `/dashboard-rooms-v11` |
| Сохранность YAML | `/dashboard-rooms/rooms` не регистрируется, не удаляется и не переписывается |
| Автономность | Один локальный `nikas-rooms-panel.js`, runtime-импортов нет |
| Фиксированная оболочка | Header / viewport / нижнее меню монтируются один раз |
| Точечные состояния | `hass`-обновления меняют text/class, не `shadowRoot.innerHTML` |
| Масштаб | 75–200%, pinch, reset двумя пальцами, локальное сохранение |
| Прокрутка | Внешняя оболочка заблокирована; скролл принадлежит рабочей области |
| Источник данных | Только HA registries и `hass.states` |
| Неизвестные данные | Явное `Нет данных`, без оптимистических значений |
| Команды | Нет прямых toggle/service calls; только штатный `more-info` |
| Версия | UI `11.0.0`, cache key и panel manifest согласованы |

## Проверка на устройстве

Автоматические проверки не заменяют обязательный тест на телефоне. До переключения ссылки из «Дома» нужно подтвердить чек-лист `PHONE_ACCEPTANCE.md`.
