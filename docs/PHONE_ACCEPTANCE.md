# Проверка Rooms v11 на телефоне

Открыть **Помещения · новая** и убедиться, что адрес — `/dashboard-rooms-v11/rooms`.

- Старая `/dashboard-rooms/rooms` по-прежнему открывается и выглядит без изменений.
- Видны все 18 помещений в правильном порядке.
- В Header отображаются `Помещения` и `UI v11.0.11`.
- Header и нижнее меню не сдвигаются при обычной и инерционной прокрутке.
- Короткий обзор не подтягивает нижнее меню вверх.
- Одно короткое нажатие по любой карточке открывает комнату; повторное нажатие не требуется.
- Кнопки меню и обновления в Header реагируют на одно нажатие.
- Центральная плашка комнаты возвращает к обзору помещений.
- Диагностика открывается, фильтры ярлыков работают, плашка возвращает в комнату.
- Карточки сущностей открывают штатное `more-info`; прямой toggle из карточки не выполняется.
- `unknown` и `unavailable` отображаются как `Нет данных` / `Требует внимания`.
- Pinch меняет только рабочую область в диапазоне 75–200%.
- Двойной тап двумя пальцами возвращает 100% и начало страницы.
- При 100% нет горизонтального сдвига; длинная диагностика прокручивается вертикально.
- После десяти переходов обзор ↔ комнаты нет белого кадра и моргания Header.
- Обновление состояний не сбрасывает текущую комнату, прокрутку или Header.
- Кнопка `Дом` открывает фактически зарегистрированную новую панель: `/dashboard-house-v11/home` либо `/dashboard-house-v12/home`; старый `/dashboard-house` не используется.
- Кнопки `Действия` и `Инфра` открывают `/dashboard-actions/home` и `/dashboard-infrastructure/overview`.
- Ссылка из панели «Дом» всё ещё ведёт на старую YAML-панель до отдельного переключения.
