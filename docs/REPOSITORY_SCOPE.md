# Область ответственности репозитория

`NikaSir/ha-nikas-rooms` владеет только новой панелью **«Помещения»** по адресу `/dashboard-rooms-v11/rooms`.

## Жёсткие границы

- `/dashboard-rooms/rooms` принадлежит существующей YAML-конфигурации и сохраняется без изменений.
- Репозиторий `NikaSir/ha-contract-generated-ui` и его панель «Дом» не изменяются.
- Ссылка «Дом → Помещения» не переключается в рамках этой версии.
- JavaScript, Python, assets и manifests других панелей не импортируются во время выполнения.
- Выгрузка интеграции удаляет только собственный `/dashboard-rooms-v11`.

## Порядок приёмки

1. Установить новую интеграцию рядом со старой YAML-панелью.
2. Проверить `/dashboard-rooms-v11/rooms` на целевом iPhone.
3. Исправить замечания без изменения старого маршрута.
4. После отдельного подтверждения изменить только входящую ссылку из панели «Дом».
5. Старую YAML-панель оставить как rollback до отдельного решения о выводе.
